# AnnaVideoPlayer — «Анна»

Лёгкий видеоплеер для Huawei и Android на Kotlin.

Проект находится в разработке. Основные задачи: локальная медиатека, группировка по папкам, превью, история просмотров, воспроизведение локальных видео и потоков через AndroidX Media3.

Исходники и GitHub Actions будут добавлены отдельным коммитом.
