# АННА · Anna Video Player

Нативный видеоплеер для Huawei и Android, созданный в честь Анны.

**Статус:** MVP 0.1.0 в разработке. Требуется успешная сборка GitHub Actions и проверка на Huawei Pura 80 Ultra (EMUI 15).

## Возможности первой версии

- Автоматический поиск локальных видео через MediaStore, без доступа ко всем файлам.
- Папки, поиск, сортировка по дате/названию/длительности/размеру.
- Превью видео и кэш миниатюр ~20 МиБ.
- История, избранное и восстановление позиции просмотра.
- AndroidX Media3 ExoPlayer: локальное видео, HTTP(S), HLS, DASH, RTSP.
- Стандартные контролы Media3, звуковые дорожки, субтитры, скорость, масштабирование, PiP.
- Русский тёмный интерфейс Jetpack Compose, без рекламы и Google Play Services.

## Ограничения

- Не гарантируется воспроизведение абсолютно всех форматов: это зависит от кодека внутри файла и декодеров Huawei. Встроенного FFmpeg/VLC-пакета пока нет.
- Онлайн-каталог фильмов, Zona и DRM-интеграция не реализованы. Сетевой раздел принимает прямые адреса потоков, к которым у вас есть доступ.
- На Android 14+ при выборочном разрешении могут отображаться только выбранные пользователем видео.
- Поддержка PiP зависит от устройства и системных настроек. Для EMUI 15 ещё нужна проверка на настоящем устройстве.
- Обычный HTTP включён для локальных камер/IPTV, но не шифрует соединение.

## Сборка APK

GitHub Actions: [Android APK](../../actions/workflows/build.yml).

Рабочая ветка: feature/initial-player. При push или ручном запуске workflow выполняются тесты и сборка debug APK:

1. Установка JDK 17, Gradle 8.13 и Android SDK API 36.
2. Запуск тестов: gradle testDebugUnitTest.
3. Сборка: gradle assembleDebug.
4. После успешной сборки APK появляется в артефакте AnnaVideoPlayer-debug.

Откройте успешный запуск Actions, скачайте артефакт, распакуйте и установите app-debug.apk.

Для локальной сборки нужны JDK 17, Gradle 8.13 и Android SDK Platform 36. Gradle Wrapper JAR пока не включён, поскольку доступной проверенной версии файла в исходной поставке нет; GitHub Actions устанавливает Gradle отдельно.

## Технологии

Kotlin 2.3.21 · Android Gradle Plugin 8.13.2 · Compose BOM 2026.09.00 · Media3 1.11.1 · Android MediaStore · SharedPreferences.

## План развития

1. Получить успешную сборку и устранить ошибки.
2. Протестировать на Huawei: разрешения, MP4/MKV/H.265, субтитры, HLS/DASH/RTSP, PiP, фоновые состояния.
3. Улучшить жесты, органы управления и по возможности добавить необязательный набор дополнительных декодеров.
4. Создать модуль онлайн-каталога с легальным провайдером.
5. Подготовить подписанный релиз с безопасным хранением ключей.

История и избранное хранятся локально. Приложение не передаёт медиатеку сторонним серверам.
