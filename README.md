# АННА · Anna Video Player

Нативный видеоплеер для Huawei и Android, созданный в честь Анны.

**Статус:** MVP 0.5.0. Требуется проверка на Huawei Pura 80 Ultra (EMUI 15).

## Возможности первой версии

- Автоматический поиск локальных видео через MediaStore, без доступа ко всем файлам.
- Папки, поиск, сортировка по дате/названию/длительности/размеру.
- Превью видео и кэш миниатюр ~20 МиБ.
- История, избранное и восстановление позиции просмотра.
- AndroidX Media3 ExoPlayer: локальное видео, HTTP(S), HLS, DASH, RTSP.
- Стандартные контролы Media3, звуковые дорожки, субтитры, скорость, масштабирование, PiP.
- Русский тёмный интерфейс Jetpack Compose, без рекламы и Google Play Services.

## Ограничения

- Не гарантируется воспроизведение абсолютно всех форматов: это зависит от кодека внутри файла и декодеров Huawei. Встроенного FFmpeg/VLC-пакета пока нет.
- Онлайн-каталог фильмов, Zona и DRM-интеграция не реализованы. Сетевой раздел принимает прямые адреса потоков, к которым у вас есть доступ.
- На Android 14+ при выборочном разрешении могут отображаться только выбранные пользователем видео.
- Поддержка PiP зависит от устройства и системных настроек. Для EMUI 15 ещё нужна проверка на настоящем устройстве.
- Обычный HTTP разрешён для совместимости с некоторыми потоками/IPTV. Такой трафик не шифруется; для чувствительных источников используйте HTTPS.

## Сборка APK

GitHub Actions: [Android APK](../../actions/workflows/build.yml).

Workflow выполняет unit-тесты и собирает Debug APK. Если настроены четыре секрета подписи, он дополнительно собирает и публикует подписанный Release APK.

### Настройка постоянной подписи

Создайте отдельный Android-keystore и сохраните его резервную копию в безопасном месте. Потеря keystore или паролей может лишить возможности выпускать обновления, совместимые с уже установленной подписанной версией.

В приватном репозитории откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте:

- `ANNAVUE_KEYSTORE_BASE64` — содержимое keystore в Base64.
- `ANNAVUE_STORE_PASSWORD` — пароль keystore.
- `ANNAVUE_KEY_ALIAS` — alias ключа.
- `ANNAVUE_KEY_PASSWORD` — пароль ключа.

Не добавляйте keystore, пароли или Base64 ключа в Git, Issues, Pull Requests или обычные файлы проекта. После настройки секретов следующий запуск GitHub Actions сможет собрать подписанный Release APK. Один и тот же ключ необходимо сохранять для всех будущих обновлений.

### Проверки

1. JDK 17, Gradle 8.13 и Android SDK API 36.
2. Unit-тесты: `testDebugUnitTest` и, при настроенной подписи, `testReleaseUnitTest`.
3. Сборка Debug: `assembleDebug`.
4. Подписанная сборка Release: `assembleRelease` (только при наличии всех четырёх секретов).

Успешная сборка не заменяет проверку на реальном Huawei и не гарантирует отсутствие предупреждений AppGallery/EMUI при установке APK из внешнего источника.

## Технологии

Kotlin 2.3.21 · Android Gradle Plugin 8.13.2 · Compose BOM 2026.04.01 · Media3 1.11.1 · Android MediaStore · SharedPreferences.

## План развития

1. Проверить сборку Debug и подписанный Release.
2. Проверить APK на Huawei: разрешения, MP4/MKV/H.265, субтитры, HLS/DASH/RTSP, PiP, фоновые состояния.
3. Улучшить жесты, органы управления и по возможности добавить необязательный набор дополнительных декодеров.
4. Создать модуль онлайн-каталога с легальным провайдером.

История и избранное хранятся локально. Приложение не передаёт медиатеку сторонним серверам.
