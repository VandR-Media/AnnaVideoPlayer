# АННА · Anna Video Player

Нативный видеоплеер для Huawei и Android, созданный в честь Анны.

**Статус:** MVP 0.5.1. Требуется проверка на Huawei Pura 80 Ultra (EMUI 15).

## Возможности первой версии

- Автоматический поиск локальных видео через MediaStore, без доступа ко всем файлам.
- Папки, поиск, сортировка по дате/названию/длительности/размеру.
- Превью видео и кэш миниатюр ~20 МиБ.
- История, избранное и восстановление позиции просмотра.
- AndroidX Media3 ExoPlayer: локальное видео, HTTPS, HLS, DASH, RTSP.
- Стандартные контролы Media3, звуковые дорожки, субтитры, скорость, масштабирование, PiP.
- Русский тёмный интерфейс Jetpack Compose, без рекламы и Google Play Services.

## Ограничения

- Не гарантируется воспроизведение абсолютно всех форматов: это зависит от кодека внутри файла и декодеров Huawei. Встроенного FFmpeg/VLC-пакета пока нет.
- Онлайн-каталог фильмов, Zona и DRM-интеграция не реализованы. Сетевой раздел принимает прямые адреса потоков, к которым у вас есть доступ.
- На Android 14+ при выборочном разрешении могут отображаться только выбранные пользователем видео.
- Поддержка PiP зависит от устройства и системных настроек. Для EMUI 15 ещё нужна проверка на настоящем устройстве.
- Обычный HTTP намеренно отключён: приложение не разрешает незашифрованные сетевые соединения. Используйте HTTPS-адрес источника. RTSP сохранён для совместимости, но сам протокол также может передавать данные без шифрования.

## Безопасность и конфиденциальность

- Сетевые соединения HTTP запрещены на уровне Android Network Security Configuration; доверие ограничено системными центрами сертификации.
- Приложение не использует рекламу, аналитику, GMS или сторонние серверы для отправки медиатеки.
- Резервное копирование приложения отключено. Для локальной медиатеки запрашивается только необходимый доступ к видео.

## Сборка APK

### Локальная сборка

Для сборки нужны JDK 17 и Android SDK с платформой API 36 и Build Tools 36.0.0. Отдельно устанавливать Gradle не требуется: в репозитории находится Gradle Wrapper 8.13.

Linux/macOS:

```bash
./gradlew --version
./gradlew --no-daemon --stacktrace clean testDebugUnitTest lintDebug assembleDebug
```

Windows:

```bat
gradlew.bat --version
gradlew.bat --no-daemon --stacktrace clean testDebugUnitTest lintDebug assembleDebug
```

Готовый Debug APK:

`app/build/outputs/apk/debug/app-debug.apk`

Wrapper загружает только Gradle 8.13 с официального HTTPS-адреса и сверяет архив с опубликованной Gradle SHA-256 суммой из `gradle-wrapper.properties`. Wrapper JAR дополнительно проверяется Gradle Setup Action в CI.

### GitHub Actions

Workflow **Android APK** выполняет:

1. Проверку Gradle Wrapper.
2. Unit-тесты.
3. Android Lint.
4. Чистую сборку Debug APK без повторного использования Gradle build cache.
5. Публикацию APK как артефакта GitHub Actions.

Для Pull Request сборка Debug выполняется без доступа к секретам подписи. Подписанный Release APK собирается только при запуске workflow на ветке `main` и наличии всех четырёх секретов. GitHub Actions используют зафиксированные commit SHA вместо плавающих тегов; Dependabot отслеживает обновления Actions и Gradle.

### Настройка постоянной подписи

Создайте отдельный Android-keystore и сохраните его резервную копию в безопасном месте. Потеря keystore или паролей может лишить возможности выпускать обновления, совместимые с уже установленной подписанной версией.

В приватном репозитории откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте:

- `ANNAVUE_KEYSTORE_BASE64` — содержимое keystore в Base64.
- `ANNAVUE_STORE_PASSWORD` — пароль keystore.
- `ANNAVUE_KEY_ALIAS` — alias ключа.
- `ANNAVUE_KEY_PASSWORD` — пароль ключа.

Не добавляйте keystore, пароли или Base64 ключа в Git, Issues, Pull Requests или обычные файлы проекта. После настройки секретов запуск workflow на `main` сможет собрать подписанный Release APK. Один и тот же ключ необходимо сохранять для всех будущих обновлений. Временный файл keystore удаляется в конце job.

### Проверки

- JDK 17.
- Gradle Wrapper 8.13 с проверкой официальной SHA-256 суммы.
- Android SDK API 36 и Build Tools 36.0.0.
- Unit-тесты: `testDebugUnitTest` и, при настроенной подписи, `testReleaseUnitTest`.
- Android Lint: `lintDebug`.
- Сборка Debug: `assembleDebug`.
- Подписанная сборка Release: `assembleRelease` (только при наличии всех четырёх секретов и запуске на `main`).

Успешная сборка не заменяет проверку на реальном Huawei и не гарантирует отсутствие предупреждений AppGallery/EMUI при установке APK из внешнего источника.

## Технологии

Kotlin 2.3.21 · Android Gradle Plugin 8.13.2 · Compose BOM 2026.04.01 · Media3 1.11.1 · Android MediaStore · SharedPreferences.

## План развития

1. Проверить сборку Debug и подписанный Release.
2. Проверить APK на Huawei: разрешения, MP4/MKV/H.265, субтитры, HLS/DASH/RTSP, PiP, фоновые состояния.
3. Улучшить жесты, органы управления и по возможности добавить необязательный набор дополнительных декодеров.
4. Создать модуль онлайн-каталога с легальным провайдером.

История и избранное хранятся локально. Приложение не передаёт медиатеку сторонним серверам.
