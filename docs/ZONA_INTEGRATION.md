# Annavue — план подключения Zona

## Текущее состояние

**Zona выбрана в качестве первого кандидата для онлайн-каталога, но интеграция НЕ работает и НЕ заявлена как реализованная.**

Проверены официальные страницы Zona: https://android.zona.pub/ и https://az1.zona.pub/faq/general-questions. На них есть сведения об официальном Android-приложении, но опубликованного официального API для стороннего встраивания каталога и получения разрешённых ссылок воспроизведения не найдено.

Перед подключением необходимо получить от владельца сервиса документацию и условия интеграции или подтвердить другой авторизованный способ работы. Не следует принимать за официальный API неаутентифицированные GitHub-проекты, скрейпинг внутреннего API или полученные обходом защиты медиапотоки.

## Архитектура

- `VideoProvider`: минимальный контракт поиска, карточки видео и разрешённого источника воспроизведения.
- `ProviderRegistry`: каталог независимых провайдеров.
- `ZonaProvider`: отключённая заглушка; без сетевых запросов, поддельного каталога или установки сторонних APK.
- `CatalogVideo`: метаданные без зависимости от конкретного источника.
- `StreamSource`: объект только для потока, полученного допустимым способом. Перед воспроизведением следует проверять URL и протокол; нельзя обходить DRM.
- Локальная библиотека MediaStore, папки, избранное и плеер остаются независимыми от онлайн-каталогов.

## Условия перехода к рабочей интеграции

1. Получить документированные и разрешённые интерфейсы Zona или явное разрешение провайдера.
2. Убедиться, что условия использования допускают каталог, постеры и воспроизведение в стороннем приложении.
3. Определить способ авторизации, ограничения запросов, правила кэширования и обработки приватных данных.
4. Реализовать адаптер отдельно от UI, тестировать без настоящих учётных данных и секретов.
5. Сделать в разделе «Сеть» интерфейс с ясным состоянием «Подключение недоступно», поиском и карточками только после появления работающего источника.
6. Проверить совместимость и воспроизведение на Huawei Pura 80 Ultra с EMUI 15, затем оценить энергопотребление и размер APK.

## Сетевая политика

По умолчанию Annavue запрещает cleartext HTTP. Доступ к HTTPS разрешён. RTSP поддерживается плеером, но не обязательно зашифрован. Исключения для HTTP можно рассматривать только для конкретных доверенных источников после проверки необходимости и угроз. Никаких скрытых установок APK, обхода подписок, копирования DRM-ключей или извлечения закрытых потоков.

## Текущая цель

Сейчас добавляется только проверяемый интерфейс провайдеров и безопасная отключённая заготовка Zona. Никакие новые разрешения Android, сетевые библиотеки и UI-компоненты для этого этапа не нужны.
